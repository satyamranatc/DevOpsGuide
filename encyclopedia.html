Docker

Container Platform
Containers
In One Line

Packs your application with all its code, libraries, and settings into one sealed box that runs identically on any computer.

Eliminates the classic "works on my machine" problem by running software inside isolated, lightweight process environments.

Docker Guide →

Nginx

Web Server & Reverse Proxy
Traffic
In One Line

A high-speed traffic host standing at the front door of your servers to serve static files and route visitors to your backend apps.

Handles SSL/TLS termination, request caching, and reverse proxying so client requests reach the appropriate ports and containers securely.

Nginx Guide →

EKS

Elastic Kubernetes Service (AWS)
Kubernetes
In One Line

Amazon's managed Kubernetes service that runs the control plane for you across 3 physical facilities with zero management overhead.

You deploy containers and worker node groups, while AWS handles master node uptime, automated backups, and version patching.

EKS Guide →

ASG (Auto Scaling Group)

AWS EC2 Elasticity · aka ADG
AWS
In One Line

An automated pool of EC2 servers that adds instances when traffic surges and terminates them when demand cools down.

Maintains healthy server minimums and automatically replaces failed or frozen virtual machines without human intervention.

AWS Essentials →

Load Balancer

ALB / NLB / CLB
Traffic
In One Line

A digital traffic cop that evenly spreads incoming visitor requests across multiple healthy servers so no single computer gets overwhelmed.

Detects unhealthy servers instantly, automatically reroutes requests, and acts as the public entry point for your infrastructure.

Load Balancer in EKS →

kubectl

Pronounced "koob-control"
Kubernetes
In One Line

The remote control command-line tool you use to inspect, create, scale, and troubleshoot anything inside a Kubernetes cluster.

Sends authenticated JSON/YAML requests to the cluster API server to view logs, restart deployments, and inspect worker nodes.

kubectl Cheat Sheet →

Kubernetes (K8s)

aka Kube / Qube
Kubernetes
In One Line

An automated operating system for the cloud that schedules, balances, scales, and self-heals containerized applications across many servers.

Acts as the head chef of your infrastructure: ensures if a container dies, another one immediately replaces it without downtime.

Kubernetes Explained →

Kubelet

Worker Node Agent
Kubernetes
In One Line

The supervisor agent running on every worker node that receives orders from the control plane and ensures assigned pods stay alive.

Checks PodSpecs, triggers container runtimes to start containers, performs health checks, and reports node status back to the API server.

Nodes in EKS →

kube-proxy

Cluster Network Forwarder
Kubernetes
In One Line

A network controller running on each worker node that maintains routing rules so pods can talk to services and each other.

Translates virtual Service IPs and ports into actual pod backend IP addresses using operating system packet filters like iptables or IPVS.

Services in EKS →

kube-apiserver

Kubernetes Front Gate
Kubernetes
In One Line

The central doorway of the cluster that validates, authenticates, and executes every command issued by users or internal controllers.

The only component that talks directly to the etcd database to store and retrieve cluster state.

Control Plane →

Pod

Atomic Compute Unit
Kubernetes
In One Line

The smallest deployable unit in Kubernetes—a disposable tray that wraps one or more tightly-coupled containers sharing IP and storage.

Pods are ephemeral: if one crashes or runs out of memory, Kubernetes destroys it and launches a brand new one.

Pods Explained →

Deployment

Pod Lifecycle Manager
Kubernetes
In One Line

A manager that guarantees a set number of pod replicas are running and safely conducts zero-downtime rolling updates.

When you push an update, it spins up new version pods before safely draining old ones so your website never displays an error.

Deployment Commands →

Service

Stable Endpoint · ClusterIP/LB
Kubernetes
In One Line

A permanent IP address and DNS name that routes traffic across a group of ephemeral, constantly shifting pods.

Because pods are created and destroyed constantly, services provide a rock-solid target for internal apps or outside visitors to reach.

Services Explained →

Ingress

HTTP/HTTPS Route Manager
Traffic
In One Line

A smart routing rulebook that directs external HTTP/HTTPS traffic to internal services based on domain names and URL paths.

Allows you to expose 50 different microservices using just one shared AWS Application Load Balancer instead of paying for 50 separate LBs.

Ingress in EKS →

ECR

Elastic Container Registry (AWS)
AWS
In One Line

Amazon's private, highly secure pantry for storing, versioning, and distributing Docker container images to EKS or EC2.

Integrates natively with AWS IAM credentials so your worker servers can pull application updates without public exposure.

Deploying from ECR →

EC2

Elastic Compute Cloud
AWS
In One Line

On-demand virtual computers you rent from AWS by the second to host code, databases, or act as Kubernetes worker nodes.

Choose CPU, RAM, GPU, and storage size on the fly and resize whenever requirements change.

EC2 Guide →

S3

Simple Storage Service
AWS
In One Line

An infinitely scalable digital filing cabinet for storing any quantity of files, images, database backups, or static websites.

Offers 99.999999999% (11 9's) durability by automatically replicating your files across multiple physical data centers.

AWS S3 Essentials →

IAM

Identity & Access Management
AWS
In One Line

The security badge office of AWS that governs exactly who (or which service) is permitted to access which cloud resources.

Enforces least-privilege security by attaching roles and policies to EKS nodes, CI/CD runners, and developers.

IAM Essentials →

VPC

Virtual Private Cloud
Traffic
In One Line

Your own private, fenced-off estate inside the AWS cloud where you launch and securely isolate your servers and databases.

Gives you complete control over IP address ranges, subnets, route tables, network gateways, and stateful firewalls.

VPC Networking →

CI/CD

Continuous Integration & Delivery
CI/CD
In One Line

An automated assembly line that tests, builds, and deploys your code to live servers every single time you push to Git.

Catches bugs before they reach production, packages container images, and removes stressful manual Friday night deployments.

CI/CD Guide →

GitHub Actions

Workflow Automation
CI/CD
In One Line

GitHub's built-in automation robot that runs tests, builds Docker containers, and updates your EKS pods when code is merged.

Configured with simple YAML files located inside .github/workflows and executed across disposable cloud virtual machines.

Actions CI/CD Guide →

Terraform

Infrastructure as Code (IaC)
CI/CD
In One Line

A blueprint tool that lets you write code to automatically build, modify, and destroy cloud servers, VPCs, and EKS clusters safely.

Replaces manual console clicking with version-controlled, repeatable text files using the simple workflow: init → plan → apply.

Terraform Guide →

Prometheus

Metrics Collector & Time-Series DB
Observability
In One Line

A 24/7 cluster doctor that periodically scrapes numbers (CPU, RAM, latency, errors) from your apps and sounds alerts when things go wrong.

Stores metric datapoints efficiently in a time-series database and triggers PagerDuty/Slack notifications via Alertmanager.

Monitoring →

Grafana

Visualization & Dashboards
Observability
In One Line

A high-tech control room dashboard that turns raw metrics and logs into real-time visual charts and cluster health graphs.

Connects seamlessly to Prometheus, CloudWatch, and Elasticsearch to show response times, active visitors, and pod health.

Grafana Guide →

Helm

Kubernetes Package Manager
Kubernetes
In One Line

The "App Store" or npm for Kubernetes that installs complex multi-part tools (databases, ingress, monitoring) with a single command.

Packages multiple YAML files into reusable, parameterized templates called Helm Charts that can be versioned and rolled back.

Helm in EKS →

etcd

Cluster Brain & Key-Value Store
Kubernetes
In One Line

The single source of truth database in Kubernetes that securely remembers the exact state and location of every pod and node in the cluster.

Uses the Raft consensus algorithm so even if server nodes crash, your cluster's configuration state is never corrupted.

EKS Control Plane →

Karpenter

High-Speed Node Autoscaler
Kubernetes
In One Line

An open-source autoscaler that observes unscheduled pods and boots up custom right-sized EC2 compute in under 45 seconds.

Powers modern AWS EKS Auto Mode, bypassing clumsy Auto Scaling Groups by directly choosing instance types matching exact CPU/RAM requests.

Auto Mode & Karpenter →

AWS Fargate

Serverless Container Compute
AWS
In One Line

A serverless container engine where you run pods without ever configuring, patching, or paying for idle EC2 virtual machines.

AWS provisions an isolated micro-VM for each container on-demand, charging you only for the exact seconds CPU and RAM are used.

Fargate →

Bash

Bourne Again Shell
Linux
In One Line

The universal command language and interpreter used to talk directly to Unix/Linux systems and automate repetitive server jobs.

The standard language used inside deployment pipelines, entrypoint scripts, and everyday terminal troubleshooting.

Shell Scripting Guide →

Route 53

AWS Cloud DNS
Traffic
In One Line

The internet's phonebook on AWS that translates human domain names (like myapp.com) into computer IP addresses.

Features health-checking, geo-routing, and alias records that seamlessly point apex domains directly to AWS Load Balancers.

Route 53 →

Security Group

Stateful Virtual Firewall
AWS
In One Line

A virtual security guard standing in front of your EC2 instances and load balancers deciding which ports and IPs are allowed in or out.

Stateful by default: if you allow inbound traffic on port 80, the return outbound traffic is automatically permitted.

Security Groups →

DaemonSet

Node Fleet Controller
Kubernetes
In One Line

A Kubernetes controller that ensures every single worker node in your cluster runs exactly one copy of a specific pod.

Essential for node-level infrastructure background jobs like Fluentd/Promtail log collectors, Datadog agents, and kube-proxy.

EKS Addons →

StatefulSet

Stateful App Manager
Kubernetes
In One Line

Manages pods that need fixed network identities, ordered rollouts, and permanent persistent disks (ideal for databases like Postgres and Kafka).

Unlike regular Deployments where pods have random hashes, StatefulSet pods get sticky names (e.g., db-0, db-1) that keep their data on restart.

Workload Types →

CloudWatch

AWS Monitoring & Logging
Observability
In One Line

AWS's native surveillance system that aggregates operational metrics, application log streams, and triggers automated alerts.

Tracks EC2 CPU utilization, collects EKS cluster audit logs, and can trigger Auto Scaling Groups when thresholds are breached.

CloudWatch →

Namespace

Virtual Cluster Divider
Kubernetes
In One Line

A virtual partition inside a Kubernetes cluster that isolates different teams, apps, or environments (like dev vs production).

Prevents naming collisions and allows administrators to set resource quotas and security policies per department.

Namespace Commands →

ConfigMap & Secret

Configuration & Credentials
Kubernetes
In One Line

Injects environment variables, settings, and encrypted credentials into your pods without rebuilding or hardcoding container images.

ConfigMaps store plaintext app settings, while Secrets store base64-encoded sensitive keys (API tokens, database passwords).
